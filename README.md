# miniC

Учебный компилятор C-подобного языка **miniC** в ассемблер **x86**, написанный на C++.

> 🚧 Проект в разработке: готовы лексический и синтаксический анализ, идёт работа над семантическим анализом, генерация кода — следующий этап.

## Пример программы на miniC

```c
int fact(int n) {
    if (n <= 1) { return 1; } // база рекурсии
    return n * fact(n - 1);
}

int main() {
    int r = fact(5);
    word mask = 1 << 3;
    bool ok = r > 100 && mask != 0;
    if (ok) { return 0; } else { return 1; }
}
```

## Язык

- Типы: `int`, `word`, `bool` (константы `true` / `false`)
- Операторы: `if` / `else`, `while`, `return`, вызовы функций с параметрами
- Выражения: арифметика `+ - * / %`, сравнения, логические `&&` `||` `!`, сдвиги `<<` `>>`
- Однострочные комментарии `//`

## Архитектура

```
исходный код (.mc)
      │
      ▼
 Lexer ── лексемы + таблица идентификаторов (хеш-таблица, метод цепочек)
      │
      ▼
 Parser ── рекурсивный спуск, приоритеты операторов → AST
      │
      ▼
 Semantic ── области видимости, проверка типов
      │
      ▼
 Генерация кода x86 (в планах)
```

| Модуль | Файлы | Что делает |
|---|---|---|
| Лексер | `Lexer.h/.cpp` | Разбивает текст на лексемы, пропускает пробелы и комментарии, сообщает об ошибках с номером строки и позицией |
| Таблица идентификаторов | `IdTable.h/.cpp` | Хеш-таблица с разрешением коллизий методом цепочек |
| Синтаксическое дерево | `Ast.h/.cpp` | Узлы AST и их вывод в консоль |
| Парсер | `Parser.h/.cpp` | Рекурсивный спуск: выражения с учётом приоритетов, операторы, функции, программа целиком |
| Семантический анализ | `Semantic.h/.cpp` | Области видимости, проверка типов, вызовов функций и возвратов (в разработке) |
| GUI | `gui*.cpp` | Редактор кода с подсветкой синтаксиса, вкладка «Дерево» с AST, вывод синтаксических ошибок (Dear ImGui + DirectX 11) |

## Сборка

Требуется Windows, CMake 3.20+ и компилятор MSVC (Visual Studio 2022 или Build Tools).

```
cmake -S . -B build
cmake --build build --config Release
```

Получатся две программы:
- `build/Release/minic_gui.exe` — редактор с графическим интерфейсом
- `build/Release/minic_cli.exe` — консольная версия
