# miniC

Учебный компилятор C-подобного языка **miniC** в ассемблер **x86** (32-битная Windows), написанный на C++.
Проходит весь путь от исходного текста до работающего `.exe`: лексический, синтаксический и семантический анализ, промежуточный код в виде триад, свёртка констант, генерация ассемблера NASM, сборка и запуск прямо из редактора.

## Пример программы на miniC

```c
int fact(int n) {
    if (n <= 1) { return 1; } // база рекурсии
    return n * fact(n - 1);
}

int main() {
    int r = fact(5);
    word mask = 1 << 3;
    bool ok = r > 100 && mask != 0;
    print(r);
    print(mask);
    print(ok);
    if (ok) { return 0; } else { return 1; }
}
```

Вывод программы:

```
120
8
true
```

## Обнаружение ошибок

Пример программы с ошибками — `miniC/sem_error.mc`:
```c
int fact(int n) {
    if (n) { return 1; }               // условие не bool
    return n * fact(n - 1, 2);         // лишний аргумент
}
```
Компилятор сообщает о каждой ошибке с номером строки и позицией.

## Язык

- Типы: `int` (16 бит со знаком), `word` (16 бит без знака), `bool` (константы `true` / `false`)
- Операторы: `if` / `else`, `while`, `return`, вызовы функций с параметрами, рекурсия
- Выражения: арифметика `+ - * / %`, сравнения, логические `&&` `||` `!`, сдвиги `<<` `>>`
- Встроенная функция `print` — выводит число или `true` / `false`
- Однострочные комментарии `//`

## Архитектура

```
исходный код (.mc)
      │
      ▼
 Lexer ───── лексемы + таблица идентификаторов (хеш-таблица, метод цепочек)
      │
      ▼
 Parser ──── рекурсивный спуск, приоритеты операторов → AST
      │
      ▼
 Semantic ── области видимости, проверка типов и вызовов
      │
      ▼
 Triads ──── промежуточный код: триады, переходы для if и while
      │
      ▼
 Optimizer ─ свёртка констант
      │
      ▼
 CodeGen ─── ассемблер x86 (NASM, Win32)
      │
      ▼
 Runner ──── nasm + link → .exe → запуск
```

| Модуль | Файлы | Что делает |
|---|---|---|
| Лексер | `Lexer.h/.cpp` | Разбивает текст на лексемы, пропускает пробелы и комментарии, сообщает об ошибках с номером строки и позицией |
| Таблица идентификаторов | `IdTable.h/.cpp` | Хеш-таблица с разрешением коллизий методом цепочек |
| Синтаксическое дерево | `Ast.h/.cpp` | Узлы AST и их вывод в консоль |
| Парсер | `Parser.h/.cpp` | Рекурсивный спуск: выражения с учётом приоритетов, операторы, функции, программа целиком |
| Семантический анализ | `Semantic.h/.cpp` | Области видимости, проверка типов, вызовов функций (число и типы аргументов) и возвратов |
| Триады | `Triads.h/.cpp` | Построение промежуточного кода из дерева |
| Оптимизатор | `Optimizer.h/.cpp` | Свёртка константных выражений с учётом 16-битной арифметики |
| Генератор кода | `CodeGen.h/.cpp` | Ассемблер x86 для NASM, подпрограммы вывода через WinAPI |
| Запуск | `Runner.h/.cpp` | Сборка `.exe` через NASM и link из Visual Studio, запуск с ограничением по времени |
| GUI | `gui*.cpp` | Редактор с подсветкой синтаксиса, вкладки «Дерево», триады и ассемблер, ошибки, сборка и запуск программы (Dear ImGui + DirectX 11) |

## Сборка

Требуется:
- Windows, CMake 3.20+ и компилятор MSVC (Visual Studio 2022 или Build Tools);
- для запуска программ на miniC — [NASM](https://www.nasm.us/) в `PATH` и компоненты C++ для x86 в Visual Studio (из них берётся `link`).

```
cmake -S . -B build
cmake --build build --config Release
```

Получатся две программы:
- `build/Release/minic_gui.exe` — редактор: анализ, триады, ассемблер, сборка и запуск программы;
- `build/Release/minic_cli.exe` — консольная версия.

## Использование консольной версии

```
minic_cli program.mc          # триады до и после оптимизации, ассемблер в program.asm
minic_cli program.mc --tree   # плюс синтаксическое дерево
```

Собрать полученный ассемблер вручную (в «x86 Native Tools Command Prompt»):

```
nasm -f win32 program.asm -o program.obj
link program.obj kernel32.lib /subsystem:console /entry:start /out:program.exe
```
